# 🧠 API RESTful - Gerenciamento Escolar

Esta é uma API desenvolvida com **Node.js** e **Express**, criada como parte de um projeto prático para gerenciamento de dados escolares. Ela fornece endpoints RESTful para operações básicas como cadastro, listagem, atualização e remoção de alunos.

---

## Funcionalidades

- Listagem de alunos
- Cadastro de novos alunos
- Atualização de dados
- Exclusão de registros
- Comunicação com frontend via JSON

---

## Tecnologias Utilizadas

- Node.js
- Express.js
- MariaDB
- Docker
- Nodemon (desenvolvimento)
- Dotenv
